# Exercise 1 - Stored Procedure

## Objective

Create and execute stored procedures in SQL Server.

## Database

EmployeeManagementSystem

## Tables

### Departments

- DepartmentID
- DepartmentName

### Employees

- EmployeeID
- FirstName
- LastName

- Salary
- JoinDate

## Stored Procedures

### sp_GetEmployeesByDepartment

Returns employee details based on DepartmentID.

Inserts a new employee record into Employees table.
