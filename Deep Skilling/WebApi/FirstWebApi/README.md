# First Web API

## Objective
Create a simple ASP.NET Core Web API and demonstrate HTTP action verbs.

## Features
- GET
- GET by ID
- POST
- PUT
- DELETE

## Technologies
- ASP.NET Core 8
- C#
- Swagger UI

## Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Swagger

Open:

```
http://localhost:5208/swagger
```
