Project conversion: Java -> C#

Prerequisites

- Install the .NET SDK (recommended: .NET 7 or later): https://dotnet.microsoft.com/download

Build & run (PowerShell)

dotnet build "FactoryMethodPatternExample\FactoryMethodPatternExample.csproj"
dotnet run --project "FactoryMethodPatternExample\FactoryMethodPatternExample.csproj"

dotnet build "SingletonPatternExample\SingletonPatternExample.csproj"
dotnet run --project "SingletonPatternExample\SingletonPatternExample.csproj"

If `dotnet` is not installed on this machine, install the SDK and re-run those commands.
